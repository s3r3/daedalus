# Daedalus Linux tray backend

A lightweight tray icon for Linux desktops: `daedalus-tray.py` (~100 lines,
stdlib only) shows the bundled placeholder "D" icon via
StatusNotifier/AppIndicator3, with a menu — Open CLI, Open Web, Status,
Quit. The Node side (`cli/src/tray-linux.ts`) implements the `TrayBackend`
interface from `cli/src/tray.ts` and injects it into `TrayManager`; menu
actions are wired in `cli/src/tray-actions.ts`.

## System dependencies (user's machine)

The helper needs Python 3 with the AppIndicator3 gir bindings:

- Arch: `sudo pacman -S libappindicator-gtk3 python-gobject`
- Debian/Ubuntu: `sudo apt install gir1.2-appindicator3-1`

`daedalus` probes for exactly this at startup (`probeAppIndicator`). When
the bindings are missing, `detectTray()` reports `available: false` with
the install line above — it never pretends the icon exists.

## How to verify on a desktop session

1. Install the dependency above, then pull/build/restart Daedalus.
2. Run `daedalus`, choose `3  Hide to Tray` — the "D" icon appears in the
   system tray; the server keeps running in the background.
3. `daedalus status` should print `Tray: tray backend ready (AppIndicator3)`.
4. Menu actions: Open CLI (opens a terminal with the launcher), Open Web
   (browser to the local Web UI), Status (terminal running
   `daedalus status`), Quit (stops the daemon and removes the icon).

## Icon assets

- `cli/assets/tray-icon.svg` — source of truth (placeholder "D"; Farid
  designs the final icon later).
- `cli/assets/tray-icon.png` — 64x64 raster for AppIndicator, generated by
  `tray/render-icon.py` (pure stdlib, no Pillow/rsvg). Re-run it after
  replacing the SVG and commit both files.

## Protocol (Node <-> helper)

`python3 daedalus-tray.py --icon <png> --menu '<json>'`; helper prints
`READY` when live, `ACTION:<id>` per click, `ERROR: <msg>` + non-zero
exit when AppIndicator3 is unavailable. Node kills the helper on `hide()`.
