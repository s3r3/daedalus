# ADR-0001: Core and Interface Boundary

## Context
Daedalus provides CLI and Web interfaces while requiring one consistent agent workflow.

## Decision
Put agent loop, planner, tools, execution, validation, recovery, events, and persistence in `@daedalus/core`. CLI and server are thin clients; the React UI only renders and submits commands.

## Consequences
Behaviour remains consistent across interfaces and is testable independently. Interfaces depend on stable core contracts and cannot contain agent logic.
