# ADR-0005: Evaluation Benchmark Scope

## Context
Thesis evaluation requires a bounded, reproducible set of software-engineering tasks and comparable measurements.

## Decision
Use N = 12 standard tasks: 4 bug fixes, 4 feature additions, and 4 refactorings. Record resolution success, turns/iterations, tool-call distribution, wall-clock duration, retry/recovery triggers, token consumption, and estimated cost.

## Consequences
The benchmark is manageable and balanced across task types. Results remain limited to the curated tasks and configured repositories; raw event logs and artifacts must be retained.
