# ADR-0003: JSON/NDJSON Event Persistence

## Context
Runs must be observable, replayable, and usable by both interfaces and later evaluation without introducing a database in the early phases.

## Decision
Store each task under `.daedalus/tasks/<task_id>/`, with append-only `events.jsonl` and current `state.json`. Events use one typed contract with monotonically increasing sequence numbers.

## Consequences
Replay and inspection are deterministic and filesystem-portable. File locking, corruption handling, and future migration must be addressed as implementation work. A database is deferred beyond Phases 0–3.
