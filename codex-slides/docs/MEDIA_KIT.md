## What it is / what it isn't

**It is:**
- An open-source slide studio that operates inside a coding agent (Codex), plus a web and desktop app.
- Image-native: each slide is composed as a full visual canvas.
- A durable, on-disk project you keep editing — research brief, outline, styles, versions, brand system.
- Visible and steerable end-to-end: you approve the brief, outline, and visual direction before rendering.

**It isn't:**
- A one-shot "type a topic, wait, download a file" black box.
- A cloud SaaS that stores your decks on someone else's servers.
- A template that just pours your text into fixed layouts.
- An OpenAI product. It *runs inside* OpenAI Codex but is an independent community project (see caveats below).

## Story angles

Each angle is a ready hook. Pick one and build the whole piece around it.

1. **"The end of the black-box slide generator."** Every other AI deck tool hides the process and hands you a file. Codex Slides shows the research, outline, style pick, and page-by-page render as it happens — and lets you stop or steer at any point.
2. **"Slides without leaving your coding agent."** Developers already live in Codex. This makes a real presentation right there, from the same repo they're working in.
3. **"Image-native decks."** Instead of filling text into a template, every slide is generated as a full visual canvas — closer to a designer's output than a PowerPoint auto-layout.
4. **"Your data never leaves your disk."** No new API keys, no uploads to a vendor cloud. It uses your existing `codex login` and writes projects locally. A privacy/ownership angle.
5. **"~5 minutes for a 10-slide deck."** Fast mode renders pages in parallel instead of one at a time. A speed/productivity angle with a concrete number.
6. **"Open-source alternative to Gamma/Tome."** Same "prompt-to-deck" promise, but agent-native, self-hostable, and free. A "build in public" angle.
7. **"From a repo/PDF to a pitch."** Point it at source files and it grounds the deck in them, with an editable research brief you can inspect. A "turn your work into a talk" angle.

## How it works in one breath

Codex conversation → open Codex Slides in the in-app Browser → create a durable project →
clarify the brief → optional source-backed research → review and edit the outline → pick a
visual direction → watch slides render (in parallel in Fast mode) → edit, mark up, restyle,
add speaker notes → present → export PPTX / PDF. Every step is on screen; the project is saved
to disk the whole way and can resume if interrupted.

## FAQ

*(English source; ask your agent to translate for a localized piece.)*

**Is it free?** Yes — open source under the MIT license. You run it yourself.

**Do I need an OpenAI API key?** No. It uses your existing ChatGPT `codex login`; no separate API key or `.env` for the default workflow.

**Where do my files and decks go?** They stay on your machine, written to a local project folder. Nothing is uploaded to a Codex Slides cloud — there isn't one.

**Can it read my repo / PDFs / spreadsheets?** Yes. Supported sources include images, PDFs, office docs, spreadsheets, Markdown, text, data files, HTML/CSS, JS, and TS.

**How fast is it, really?** Fast mode renders pages in parallel (up to four at once). A 10+ slide deck typically lands in about 4–5 minutes. Actual time varies with your machine, the model, and how complex each page is.

**What can I export?** Real PPTX and print-ready PDF, with speaker notes preserved. Render quality up to 4K and five aspect ratios (16:9, 4:3, 1:1, 9:16, 3:4).

**Is the exported PowerPoint editable?** The layout is a full-slide image per page, so text isn't individually editable in PowerPoint today. Editable-shape export is on the roadmap.

**Does it only work in Codex?** Today it's built for OpenAI Codex, and also ships as a standalone web app and a macOS/Windows/Linux desktop app. Broader "bring-your-own-agent" support is on the roadmap.

**Is this made by OpenAI?** No. It's an independent, community open-source project that *runs inside* Codex. It is not made by, endorsed by, or affiliated with OpenAI.

**What languages does it support?** The UI ships in English, Simplified Chinese, and Japanese.
