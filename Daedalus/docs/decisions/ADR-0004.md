# ADR-0004: Workspace Layout and Scaffolding

## Context
The framework needs clear package boundaries while preserving the existing Vite application.

## Decision
Under `Daedalus/`, use `core/`, `cli/`, `server/`, existing `daedalus-web/`, `evaluation/`, `docs/`, and `scripts/`. The five reference clones remain read-only siblings. The web project is adopted in place and is not recreated or migrated.

## Consequences
Core contracts are shared by CLI, server, web, and evaluation. Package boundaries are explicit. Existing frontend files remain stable while features are added incrementally.
