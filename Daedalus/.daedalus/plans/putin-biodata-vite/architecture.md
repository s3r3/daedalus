# Architecture

## Stack
- **Framework**: Vite + React 18 + TypeScript
- **Styling**: CSS modules (generated by Vite template)
- **Build**: Vite bundler
- **Assets**: Static image downloaded into `public/` or `src/assets/`
- **Hosting**: Static export (dist/)

## Components
- `App.tsx`: Main container
- `BiodataCard.tsx`: Displays photo, name, title, birth date, and career summary in a card layout

## Data Model
Static TypeScript object in component:

```typescript
const putinBiodata = {
  name: "Vladimir Vladimirovich Putin",
  title: "Presiden Federasi Rusia",
  birthDate: "7 Oktober 1952",
  birthPlace: "Leningrad, Uni Soviet (sekarang Saint Petersburg, Rusia)",
  photo: "/putin.jpg",
  career: [
    "Paragraph 1: KGB service, early political career...",
    "Paragraph 2: Presidency, major policies..."
  ]
}
```

## Routes
Single-page app, no routing library needed.

## Target Files

### Created by Vite generator (already exist)
- `jojo/package.json`
- `jojo/tsconfig.json`
- `jojo/vite.config.ts`
- `jojo/index.html`
- `jojo/src/main.tsx`
- `jojo/src/App.tsx`
- `jojo/src/App.css`

### Modified by implementation
- `jojo/src/App.tsx` — replace default with biodata display
- `jojo/src/App.css` — card layout, responsive styles
- `jojo/public/putin.jpg` — downloaded photo (openly licensed)

## Storage Decision
No backend or database. All data hardcoded in React component.

## Build Output
`jojo/dist/` — static HTML/JS/CSS bundle deployable to any static host.
